# RAG-Based-Document-Retrieval-System-OpenAI-ChromaDB-
Engineered an end-to-end Retrieval-Augmented Generation (RAG) platform combining LangChain, ChromaDB, and OpenAI API to reduce factual hallucinations in AI responses.  Developed a dynamic context retrieval engine utilizing vector similarity search to query high-relevance chunks and inject real-time grounded context into LLM prompts.
